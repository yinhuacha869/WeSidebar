# WeSidebar

**PC 微信侧边栏助手**

</div>

---

## 一、这是什么

WeSidebar 是一款运行在 Windows 上的微信侧边栏工具。启动后会自动吸附在微信主窗口右侧，在聊天的同时即可查看客户资料、历史聊天记录、话术素材与统计数据，并支持一键把话术发送到微信输入框。

所有数据均在本地处理，不上传任何服务器。

## 二、功能一览

### 1. 侧边栏
- 自动吸附微信窗口右侧，跟随微信移动、缩放
- 支持钉住置顶、最小化到托盘常驻
- 微信重启后自动重新连接，无需重启侧边栏

### 2. 当前会话（默认页）
- 自动识别微信当前聊天的联系人，实时同步
- 一屏查看联系人头像、昵称、备注
- 联系人标签管理：新建标签、打标签、删除标签
- 跟进备注：以富文本记录跟进过程，可插入图片，按时间倒序展示，可删除
- 互动统计：与该联系人的消息总数、首末联系时间一目了然
- 可随时弹出与该联系人的完整聊天记录

### 3. 聊天记录
- 会话列表：按最后消息时间排列，支持关键词搜索、滚动分页
- 多账号切换：多开/多账号登录时，可切换查看不同账号的会话
- 完整消息气泡展示，支持：
  - 图片（自动解密显示）
  - 语音（在线播放 + 语音转文字内容）
  - 动画表情、自定义表情
  - 文件、名片、小程序、链接图文
  - 引用消息（自动回溯被引用的原文）
  - 视频号直播/名片、系统消息、拍一拍等
- 历史记录上滑加载，自动定位到最新消息
- 新消息提醒：侧边栏实时提示未读，会话列表页自动置顶更新

### 4. 快捷话术
- 话术分组管理：新建、重命名、排序、删除
- 一条话术可包含多段内容：富文本 + 文件，按顺序一键依次发送到微信输入框
- 富文本编辑器编辑话术，支持插图
- 素材上传：图片、音视频、文档、压缩包等常用格式（单个不超过 50MB）
- 全局搜索条：任意页面底部随时输入关键词，快速调出话术发送
- 自动记录话术使用次数与最后使用时间

### 5. 消息统计
- 今日 / 本周两种时间维度
- 消息总量、活跃联系人数
- 消息量趋势图（按小时 / 按天）
- 消息类型分布（文本、图片、语音、文件等占比）

### 6. 聊天记录导出
- 支持导出单个联系人的完整聊天记录
- 三种格式：JSONL（ChatLab 格式，适合二次分析）、JSON、CSV（Excel 可直接打开）
- 大数据量后台导出，不影响正常使用；完成后可直接下载，也可删除导出文件
- 支持多选会话批量导出

### 7. AI 助手（可选）
- 在设置页填入您自己的 OpenAI 兼容接口地址、模型名称与密钥即可启用
- 支持一键测试连接是否可用
- 密钥加密保存在本机，不会明文展示，也不会写入日志

### 8. 系统维护
- 媒体缓存管理：查看缓存占用，一键清理，自动控制容量上限（可在配置中调整，默认 2048MB）
- 版本信息查看

## 三、环境要求

| 项目 | 要求 |
|------|------|
| 操作系统 | Windows 10 / 11（64 位） |
| 微信 | PC 版 4.1.7.x~4.1.13.x（不同小版本自动适配，过旧版本部分功能不可用） |
| 运行环境 | WebView2 Runtime（Windows 11 自带） |
| 权限 | 需以管理员身份运行（用于读取微信数据） |

## 四、快速上手

1. 启动 WeSidebar（首次运行请允许管理员权限）
2. 登录微信并打开主窗口，侧边栏会自动吸附到微信右侧
3. 在微信中切换聊天对象，侧边栏会自动跟随显示对应客户资料
4. 常用入口：
   - 「画像」：查看/编辑客户标签与跟进备注
   - 「会话」：翻看历史消息、搜索会话、导出记录
   - 「话术」：维护话术素材，双击即可发送到微信输入框
   - 「统计」：查看消息数据看板
   - 「设置」：配置 AI 助手、清理缓存

> 提示：发送话术后默认只填入微信输入框不自动发出，确认内容无误后手动回车即可；如需自动发送，可在话术发送按钮中选择自动回车模式。

## 五、数据与隐私

- 聊天记录、媒体文件、标签备注等全部数据仅保存在本机（`我的文档\WeSidebar` 目录），不连接任何外部服务器
- AI 功能仅在您主动配置接口后才会联网，且只发送聊天文本内容；不配置则该功能完全离线
- 请在合法合规的前提下使用本工具，仅处理自己账号的聊天数据，尊重他人隐私

## 六、常见问题

| 问题 | 解决方法 |
|------|----------|
| 侧边栏没有吸附到微信 | 确认微信窗口标题为「微信」，且以管理员身份运行 WeSidebar |
| 看不到账号 / 聊天记录为空 | 确认微信已登录且版本为 4.x；微信升级后如仍异常，等待适配更新 |
| 图片 / 语音无法显示 | 消息媒体按需解密，请确认对应的聊天记录存在于本机微信中 |
| 微信重启后数据断了 | 无需操作，WeSidebar 会自动重新读取 |
| AI 连接失败 | 在设置页检查接口地址（需以 http/https 开头）、模型名称与密钥 |
| 功能异常（读不到数据 / 发消息无效） | 本工具需调用 ReadProcessMemory 读取微信内存、SendInput 模拟输入，可能被 360 等杀毒软件拦截。如功能异常，请先尝试关闭杀毒软件或将 WeSidebar 加入白名单后再试 |

## 七、其他

- WeSidebar 由主程序与本地数据组成，卸载时直接删除程序目录与 `我的文档\WeSidebar` 数据目录即可
- 反馈问题请附上 `logs` 目录中最新日期的日志文件
